# Kozmoloji

Materyal düzlemin çevresinde, yörüngesinde dönen düzlemler var. Bir düzlem Eberron'a yaklaşınca etkileri dünyada hissediliyor ve oraya geçmek kolaylaşıyor.

| Düzlem | Ne? |
|---|---|
| Dolurrh | Ölüler, ruhlar ve gölgeler diyarı |
| [[Xoriat]] | Delilik. Druidler kapılarını mühürledi |
| Fernia / Risia | Ateş ve buz. Birçok büyülü araca güç veriyorlar |
| Shavarath | Melek, iblis ve şeytanların sonsuz savaşı |
| Dal Quor | Rüyalar düzlemi ([[Kalashtar]], Quori) |
| Daanvi | Düzenin kalesi |
| Irian | Yaşam ve semavi varlıklar ([[Kayıp Işık Vadisi]]) |
| Baator / Abyss | Şeytanlar / iblisler |
| Kythri | Sürekli şekil değiştiren kaos |
| Lamannia | Uçsuz bucaksız orman |
| Mabar | Saf negatif enerji |
| Syrania | Sonsuz gökyüzü. Sharn'ın uçan kısımları buna bağlı |
| Thelanis | Peri ırklarının anavatanı ([[Grayfinger]]?) |


> Kaynak: *Eberron Lore* belgesi.
